# Rust Poker Engine

`Rust Poker Engine` is an open-source Rust library for poker-related software.

[Repository](https://github.com/Subzero710/Rust_Poker_Engine) ·
[Issues](https://github.com/Subzero710/Rust_Poker_Engine/issues)

## Installation

Clone the repository:

```bash
git clone https://github.com/Subzero710/Rust_Poker_Engine.git
cd Rust_Poker_Engine
```

Build the library:

```bash
cargo build
```

## Quick start

Run the test suite:

```bash
cargo test
```

Run the project checks:

```bash
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```
